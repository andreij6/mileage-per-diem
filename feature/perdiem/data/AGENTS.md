# feature:perdiem:data

**Purpose:** Implements the per diem domain interfaces over the bundled GSA rates database, the app database's `stay` table and the settings DataStore.

**Public API:** `PerDiemDatabase` (separate read-only Room DB, `createFromAsset("perdiem.db")`, built lazily via `dagger.Lazy`, opened on first query) with `PerDiemDao`. Everything else is `internal` and bound in `PerDiemDataModule`:
- `RoomPerDiemRateRepository`: FTS4 prefix search (`bos` → `bos*`, every word prefixed, punctuation dropped) over city, state and county, non-standard locations of the requested fiscal year only, ordered by city then state, max 50. Unknown location ids fall back to the standard CONUS rate (latest FY). `fiscalYearFor` comes from the domain default.
- `RoomStayRepository`: `core:database` `StayDao`; dates as epoch days, money as cents.
- `DataStoreRecentSearchRepository`: `@SettingsStore`, key `perdiem_recent_location_ids` (comma-separated ids, most recent first, keeps 5), resolved to locations through `PerDiemDatabase`.

**Schema (`perdiem.db`, version 1, exported to `schemas/`):** `location(id, fy, city, state, county, isStandard, mieTotalCents)`, `lodging(locationId, month 1–12, cents)`, `mie(fy, totalCents, breakfastCents, lunchCents, dinnerCents, incidentalsCents, firstLastCents)`, `location_fts` (FTS4, external content `location`: city, state, county). Location id 1 is the standard rate (`Standard rate, CONUS`).

**Bundled data:** `src/main/assets/perdiem.db` is generated by `tools:perdiem-import` from the GSA Per Diem API (FY2027: 298 locations, 5 M&IE tiers, standard $113 / $68). Changing an entity changes Room's identity hash: rebuild this module (re-exports the schema), then regenerate the asset (see `tools/perdiem-import/AGENTS.md`). Bump the DB version for a new fiscal year; `fallbackToDestructiveMigration` re-copies the asset.

**Allowed dependencies:** perdiem domain, core:model, core:common, core:database, core:datastore, Room, DataStore, Hilt.

**Tests (Robolectric, `src/test`):** `RoomPerDiemRateRepositoryTest` (in-memory DB seeded by `seededPerDiemDatabase`: prefix search, FY filter, rate mapping, standard fallback, and the real asset opened through `createFromAsset`), `RoomStayRepositoryTest` (in-memory `MileageDatabase`), `DataStoreRecentSearchRepositoryTest` (temp-file DataStore: ordering, dedupe, limit 5).

Rules: see the root `AGENTS.md` (no comments, fakes not mocks).
